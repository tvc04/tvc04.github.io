# The Legend of Zelda NES Remake (p1_gold):
For this project, I worked on a lot of our design implementations. I made a lot of the dungeon's enemies, created the room transitions, and implemented all of the custom mechanics in the second dungeon (among other smaller contributions). This project was created in the Unity game engine using C#.
Link to game hosted on itch.io: <https://tommyvc04.itch.io/the-legend-of-zelda-nes-remake>

# Spar of Spade (p2_gold):
For this project, I created a haunted mine themed, roguelike dungeon crawler. The interesting and novel mechanic I implemented was requiring the player to choose an enemy to add to the dungeon everytime they complete it. Along with the purchasable upgrades, this allows the player to synergize their loadout to better counter the enemies they choose to take on. This project was created in the Unity game engine using C#.
Link to game hosted on itch.io: <https://tommyvc04.itch.io/spar-of-spade>

# SHELLS (p3_gold):
This project was a three month project taken on by our group, Almost8Bit. We aimed to create a local multiplayer versus game designed to be enjoyed in a game expo environment. To do this, we looked to create a cross between Rounds and Wii Tanks. We took inspiration from Rounds through our chaotic yet synergistic upgrade system where the loser of each round gets to choose from 4 random upgrades. We took inspiration from Wii Tanks through the simplistic theming and 2D top down visuals and movement. Throughout this project, I focused on creating a lot of the smaller quality of life visuals. The most obvious systems I worked on were designing and creating the main menu's distinct gameplay preview, implementing the "slot machine" effect when the upgrade menu comes onto screen (having each upgrade sweep in one by one while quickly switching between different upgrades), and coloring the bullets and upgrades to match the corresponding player. I also played an important role in solving our controller detection issues. In the upgrade menu, we needed to figure out how to disable the controller of the winning player so they couldn't accidentally choose an upgrade for the other player. We had trouble detecting the correct controller, reenabling controllers entirely, and losing inputs if the keyboard or mouse was touched during gameplay. I was able to figure out how to solve this, leading to a much more cohesive and understandable game since the player's could more easily understand what to do.
Link to game hosted on itch.io: <https://erikpaa.itch.io/shells>
